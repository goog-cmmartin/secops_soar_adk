# AI Generation Playbook: AWS VPC Flow Logs (`AWS_VPC_FLOW`)

## 1. Overview & Log Purpose
AWS Virtual Private Cloud (VPC) Flow Logs capture detailed telemetry on IP traffic traversing network interfaces (ENIs), Subnets, VPCs, and Transit Gateways across an AWS infrastructure. 

### Activities & Telemetry Recorded
* **Traffic Disposition**: Traffic allowed or denied by VPC Security Groups and Network Access Control Lists (NACLs).
* **Layer 3 & 4 Metadata**: Source/destination IPv4/IPv6 addresses, source/destination layer 4 ports, IANA protocol numbers, TCP control flags, and packet/byte volumes.
* **AWS Topology & Routing Context**: Source/destination VPCs, subnets, Availability Zones (AZs), AWS Regions, AWS service endpoints (e.g., S3, EC2), flow direction (`ingress`/`egress`), and routing paths (`IGW`, `NatGateway`, `VpcPeering`, `TransitGateway`).
* **Container Context (v7/ECS)**: ECS Task IDs, Task ARNs, Container Instance IDs, and Cluster ARNs.
* **OCSF / Security Lake Objects**: Standardized cybersecurity schema mappings (v1.1.0+) for centralized data lakes.

---

## 2. Format Specifications

AWS VPC Flow Logs can be delivered to **Amazon CloudWatch Logs**, **Amazon S3**, or **Kinesis Data Firehose** in multiple layout structures:

| Format Variation | Classification | Framing / Structure | Delimiter & Quoting |
| :--- | :--- | :--- | :--- |
| **Default Format (v2)** | Space-delimited Plaintext | Single-line ASCII | Single space (` `). Hyphen (`-`) for missing values. No quotes. |
| **Custom Format (v3–v5)** | Space-delimited / CSV | Single-line ASCII | Single space (` `) or comma (`,`). Missing values as `-`. |
| **Transit Gateway (v6)** | Space-delimited Plaintext | Single-line ASCII | Single space (` `). Prefixed with `6 TransitGateway`. |
| **ECS Extended (v7)** | JSON Object | Single-line JSON | Standard JSON formatting; strings double-quoted, numbers unquoted, nulls as `null` or `"-"`. |
| **OCSF v1.1.0** | Nested JSON Object | Single-line JSON | AWS Security Lake standardized OCSF Network Activity (Class `4001`). |
| **Syslog Wrapped** | Syslog RFC 3164 / 5424 | `<PRI>TIMESTAMP HOSTNAME vpc_log` | Syslog header followed by space-delimited text flow payload. |

## 3. Schema Breakdown & Fields

### 3.1 Standard & Extended Space-Delimited Fields (v2 – v5)

| Field Name | Type | Allowed / Expected Values | Description |
| :--- | :--- | :--- | :--- |
| `version` | Integer | `2`, `3`, `4`, `5`, `6`, `7` | The VPC Flow Log version. |
| `account-id` | String | `[0-9]{12}` or `unknown` | 12-digit AWS Account ID. |
| `interface-id` | String | `eni-[0-9a-f]{8,17}` | Elastic Network Interface ID. |
| `srcaddr` | String | IPv4 / IPv6 (e.g., `10.0.1.25`, `198.51.100.4`) | Source IP address. Set to `-` if `NODATA`. |
| `dstaddr` | String | IPv4 / IPv6 (e.g., `10.0.2.80`, `203.0.113.195`) | Destination IP address. Set to `-` if `NODATA`. |
| `srcport` | Integer | `0`–`65535` | Source port (Layer 4). Set to `-` if protocol is ICMP or `NODATA`. |
| `dstport` | Integer | `0`–`65535` | Destination port (Layer 4). Set to `-` if protocol is ICMP or `NODATA`. |
| `protocol` | Integer | `6` (TCP), `17` (UDP), `1` (ICMP), `58` (ICMPv6) | IANA protocol number. |
| `packets` | Integer | Positive integer (e.g., `1`, `45`, `1024`) | Total packets transferred in the capture window. |
| `bytes` | Integer | Positive integer (e.g., `40`, `5016`, `1048576`) | Total bytes transferred in the capture window. |
| `start` | Integer | Unix Epoch timestamp (seconds) | Start of the capture window. |
| `end` | Integer | Unix Epoch timestamp (seconds) | End of the capture window (`end >= start`). |
| `action` | String | `ACCEPT`, `REJECT`, `-` | Security group / NACL verdict (`-` during `NODATA`/`SKIPDATA`). |
| `log-status` | String | `OK`, `NODATA`, `SKIPDATA` | Record status. `NODATA` = no traffic in window; `SKIPDATA` = internal capacity skip. |
| `vpc-id` | String | `vpc-[0-9a-f]{8,17}` or `-` | The VPC ID where the interface resides. |
| `subnet-id` | String | `subnet-[0-9a-f]{8,17}` or `-` | The Subnet ID where the interface resides. |
| `instance-id` | String | `i-[0-9a-f]{8,17}` or `-` | The EC2 instance ID (if ENI is attached to an instance). |
| `tcp-flags` | Integer | Bitmask integer: `0`, `2` (SYN), `3` (SYN+FIN), `18` (SYN+ACK), `19` (SYN+ACK+FIN), `4` (RST), `16` (ACK), `24` (PSH+ACK) | Cumulative bitmask of TCP flags seen during aggregation. |
| `type` | String | `IPv4`, `IPv6`, `-` | Layer 3 IP type. |
| `pkt-srcaddr` | String | IPv4 / IPv6 or `-` | Original source IP of packet (distinguishes NAT/Proxy). |
| `pkt-dstaddr` | String | IPv4 / IPv6 or `-` | Final destination IP of packet. |
| `region` | String | `us-east-1`, `eu-west-1`, `ap-northeast-1`, etc. | AWS Region containing the ENI. |
| `az-id` | String | `use1-az1`, `euw1-az2`, `apse1-az3`, etc. | Availability Zone ID. |
| `sublocation-type` | String | `wavelength`, `outpost`, `localzone`, `-` | Sublocation category. |
| `sublocation-id` | String | String identifier or `-` | Sublocation ID. |
| `pkt-src-aws-service`| String | `S3`, `EC2`, `AMAZON`, `DYNAMODB`, `-` | AWS service generating the packet. |
| `pkt-dst-aws-service`| String | `S3`, `EC2`, `AMAZON`, `DYNAMODB`, `-` | AWS service receiving the packet. |
| `flow-direction` | String | `ingress`, `egress`, `-` | Traffic direction relative to the ENI. |
| `traffic-path` | Integer | `1` (IGW), `2` (VGW), `3` (Direct Connect), `4` (Peering), `5` (VPC Endpoint), `6` (NAT Gateway), `7` (Transit GW), `8` (Local GW), `-` | Egress/ingress routing path index. |

## 4. Timestamp & Dynamic Time Templating

AWS VPC Flow Logs rely on **Unix Epoch timestamps** for capture aggregation windows. When generating synthetic data, all timestamps must be generated using dynamic macro templating.

### Supported Dynamic Time Macros:
* `##$Epoch-0d0h5m0s$##` -> Produces 10-digit Unix Epoch timestamp in seconds (e.g., `1738000000`).
* `##$EpochMs-0d0h5m0s$##` -> Produces 13-digit Unix Epoch timestamp in milliseconds (e.g., `1738000000000`).
* `##$SyslogTime-0d0h5m0s$##` -> Produces BSD Syslog format timestamp (e.g., `Jan 27 14:32:10`).
* `##$TimeStamp-0d0h5m0s$##` -> Produces ISO 8601 UTC timestamp (e.g., `2026-01-27T14:32:10Z`).

### Capture Window Delta Rules:
* Flow logs aggregate across capture intervals (standard aggregation window is 1 minute to 10 minutes).
* For a log window: `end` must be equal to or greater than `start`.
  * `Start`: `##$Epoch-0d0h5m0s$##`
  * `End`: `##$Epoch-0d0h4m0s$##` (60-second window)

## 6. Key Constraints & Pitfalls

1. **Strict Field Alignment & Ordering**:
   * In space-delimited text versions, columns are parsed by exact position. Never insert extra spaces or remove delimiter columns unless matching a defined custom format string.
   * If a custom format specifies a layout (e.g., `account-id action az-id bytes ...`), the generated output must precisely mirror that sequence.

2. **Null/Missing Value Representation**:
   * Space-delimited and CSV formats **must** use a single hyphen (`-`) for missing, empty, or unresolvable fields (e.g., `instance-id` when an ENI is attached to an ALB/NAT Gateway).
   * JSON schemas utilize either `"-"` (for string identifiers) or `null` (for object/numeric fields) as specified in the schema.

3. **Status Code Dependencies (`NODATA` & `SKIPDATA`)**:
   * When `log-status` is `NODATA`: `srcaddr`, `dstaddr`, `srcport`, `dstport`, `protocol`, `packets`, `bytes`, and `action` **must** be set to `-` (or `null` in JSON).
   * When `log-status` is `SKIPDATA`: Traffic was skipped due to internal AWS throttling; standard traffic metrics are also `-`.

4. **Logical Field Consistency**:
   * **TCP Flags**: Only set non-zero integers (e.g., `2`, `18`, `19`, `24`) when `protocol` is `6` (TCP). For UDP (`17`) or ICMP (`1`), `tcp-flags` should be `0` or `-`.
   * **ICMP Traffic**: When `protocol` is `1` or `58`, `srcport` and `dstport` represent ICMP Type and Code, or are `-`.
   * **Timestamps**: Ensure `end >= start`. A standard capture interval is 60 seconds (1 minute aggregation) or 600 seconds (10 minute aggregation).

5. **JSON Key Casing**:
   * Version 7 (ECS) CloudWatch format uses Pascal/Snake hybrid casing: `Version`, `Account_id`, `Interface_id`, `Srcaddr`, `Dstaddr`, `Tcp_flags`.
   * OCSF JSON format uses lower-case snake_case: `metadata`, `cloud`, `src_endpoint`, `dst_endpoint`, `connection_info`, `traffic`. Do not mix case styles across formats.
