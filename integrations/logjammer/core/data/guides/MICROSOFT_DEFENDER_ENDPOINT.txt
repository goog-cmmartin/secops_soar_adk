# AI Generation Playbook: Microsoft Defender for Endpoint (MDE) Streaming Telemetry

---

## 1. Overview & Log Purpose

**Microsoft Defender for Endpoint (MDE)** is an enterprise endpoint detection and response (EDR) and endpoint protection platform (EPP). When configured to export raw event telemetry via Azure Monitor / Event Hub / Azure Storage diagnostic settings, it publishes high-fidelity Advanced Hunting telemetry streams.

### Primary Activities Recorded:
* **Process Activities (`DeviceProcessEvents`)**: Process creation, command line arguments, parent-child relationships, integrity levels, and hash verification.
* **Network Traffic (`DeviceNetworkEvents`, `DeviceNetworkInfo`)**: Outbound/inbound TCP/UDP connections, listening ports, remote IPs/URLs, and adapter configurations.
* **Authentication & Access (`DeviceLogonEvents`)**: Local, network, interactive, and service logons, user SIDs, authentication protocols, and failure reasons.
* **File System (`DeviceFileEvents`)**: File creation, modification, deletion, renaming, and file origin indicators.
* **Registry (`DeviceRegistryEvents`)**: Key/value modifications, deletions, and value types (e.g., `REG_SZ`, `REG_DWORD`).
* **Binary Loads (`DeviceImageLoadEvents`)**: DLL and driver module loads into memory space.
* **System & Security Events (`DeviceEvents`)**: PowerShell script execution, AMSI detections, SmartScreen warnings, local account manipulation, kernel remote API calls (`NtAllocateVirtualMemory`), and service installations.
* **Alerts (`DeviceAlertEvents`)**: Native MDE detections, antivirus alerts, and MITRE ATT&CK mappings.
* **Asset Inventory (`DeviceInfo`)**: OS version, machine group, logged-on users, and Azure AD / Entra enrollment status.

---

## 2. Format Specification

* **Log Format**: JSON (Single-line NDJSON / JSON Lines).
* **Wrapper Specification**: Azure Monitor Diagnostic Log format for Microsoft 365 Defender.
* **Character Encoding**: UTF-8.
* **Escaping & Quoting Rules**:
  * All JSON string values are double-quoted.
  * Windows file paths require double-escaped backslashes (`C:\\Windows\\System32\\cmd.exe`).
  * Nested objects within fields such as `properties.AdditionalFields`, `properties.LoggedOnUsers`, `properties.IPAddresses`, and `properties.DnsAddresses` are **stringified JSON** (JSON objects/arrays encoded as escaped strings inside the outer JSON).
  * Double quotes inside command lines or nested scripts must be escaped with `\"` or `\\\"` depending on the nesting depth.

### 3.4. Category-Specific Schema Details

#### A. `AdvancedHunting-DeviceProcessEvents`
* **`ActionType`**: `"ProcessCreated"`, `"ProcessTerminated"`
* **Core Fields**:
  * `FileName`: Name of the spawned process (`powershell.exe`, `rundll32.exe`, `whoami.exe`).
  * `FolderPath`: Target executable folder path.
  * `ProcessCommandLine`: Full execution command line.
  * `ProcessId`: Spawned Process ID (PID).
  * `ProcessCreationTime`: Timestamp when process spawned.
  * `ProcessIntegrityLevel`: `"System"`, `"High"`, `"Medium"`, `"Low"`.
  * `ProcessTokenElevation`: `"TokenElevationTypeDefault"`, `"TokenElevationTypeFull"`, `"TokenElevationTypeLimited"`.
  * `AccountDomain`, `AccountName`, `AccountSid`, `AccountUpn`, `AccountObjectId`, `LogonId`.
  * `MD5`, `SHA1`, `SHA256`, `FileSize`.

#### B. `AdvancedHunting-DeviceFileEvents`
* **`ActionType`**: `"FileCreated"`, `"FileModified"`, `"FileDeleted"`, `"FileRenamed"`, `"FileOpen"`
* **Core Fields**:
  * `FileName`: Name of target file.
  * `FolderPath`: Absolute file path.
  * `FileSize`: Size in bytes.
  * `MD5`, `SHA1`, `SHA256`: Hash strings or `null`.
  * `PreviousFileName`, `PreviousFolderPath`: Used for `"FileRenamed"` events.
  * `RequestProtocol`: `"Local"`, `"SMB"`, `"NFS"`.
  * `RequestAccountName`, `RequestAccountDomain`, `RequestAccountSid`.

#### C. `AdvancedHunting-DeviceNetworkEvents`
* **`ActionType`**: `"ConnectionSuccess"`, `"ConnectionFailed"`, `"ListeningConnectionCreated"`, `"InboundConnectionAccepted"`
* **Core Fields**:
  * `LocalIP`: IPv4 / IPv6 of local host.
  * `LocalPort`: Source ephemeral port (e.g., `49152`–`65535`).
  * `RemoteIP`: Target IP address (RFC 1918 or Public).
  * `RemotePort`: Destination port (`80`, `443`, `53`, `445`, `8080`, `8443`).
  * `RemoteUrl`: Destination URL / FQDN (e.g., `https://login.microsoftonline.com`).
  * `Protocol`: `"TcpV4"`, `"TcpV6"`, `"UdpV4"`, `"UdpV6"`.

#### D. `AdvancedHunting-DeviceLogonEvents`
* **`ActionType`**: `"LogonSuccess"`, `"LogonFailed"`, `null`
* **Core Fields**:
  * `LogonType`: `"Interactive"`, `"RemoteInteractive"` (RDP), `"Network"` (SMB/RPC), `"Service"`, `"CachedInteractive"`, `"Batch"`, `"Unlock"`.
  * `AccountName`, `AccountDomain`, `AccountSid`, `LogonId`.
  * `FailureReason`: `"InvalidUserNameOrPassword"`, `"AccountDisabled"`, `"UnknownUserOrBadPassword"`, `null`.
  * `Protocol`: `"Negotiate"`, `"Kerberos"`, `"NTLM"`, `"MICROSOFT_AUTHENTICATION_PACKAGE_V1_0"`.
  * `RemoteIP`, `RemotePort`, `RemoteDeviceName`.
  * `AdditionalFields`: Stringified JSON containing `{"IsLocalLogon": true/false, "Upn": "..."}`.

#### E. `AdvancedHunting-DeviceRegistryEvents`
* **`ActionType`**: `"RegistryValueSet"`, `"RegistryKeyCreated"`, `"RegistryKeyDeleted"`, `"RegistryValueDeleted"`
* **Core Fields**:
  * `RegistryKey`: Full hive & key path (`HKEY_LOCAL_MACHINE\\SOFTWARE\\Microsoft\\Windows\\CurrentVersion\\Run`).
  * `RegistryValueName`: Target entry name (e.g., `"CrashHeartbeat"`, `"RunKey"`).
  * `RegistryValueData`: String or numeric representation of value.
  * `RegistryValueType`: `"String"`, `"ExpandString"`, `"Binary"`, `"Dword"`, `"Qword"`, `"MultiString"`.
  * `PreviousRegistryKey`, `PreviousRegistryValueName`, `PreviousRegistryValueData`.

#### F. `AdvancedHunting-DeviceEvents` (Generic / System / Antivirus / Script Telemetry)
* **`ActionType`**:
  * `"PowerShellCommand"`
  * `"DnsQueryResponse"`
  * `"AntivirusDetection"`
  * `"SmartScreenUrlWarning"`
  * `"ServiceInstalled"`
  * `"NtAllocateVirtualMemoryRemoteApiCall"`
  * `"ProcessPrimaryTokenModified"`
  * `"ScriptContent"`
  * `"GetClipboardData"`
* **Core Fields**:
  * `AdditionalFields`: Heavily populated stringified JSON depending on `ActionType`:
    * *PowerShellCommand*: `{"Command": "Get-Process | Where-Object ..."}`
    * *DnsQueryResponse*: `{"DnsQueryString": "domain.com", "DnsQueryResult": ["{\"DnsQueryType\":\"A\",\"Result\":\"1.2.3.4\"}"]}`
    * *AntivirusDetection*: `{"ThreatName": "Trojan:Win32/CobaltStrike", "WasRemediated": true, "WasExecutingWhileDetected": false, "ResourceSchema": "file", "ReportSource": "WindowsDefender"}`
    * *ServiceInstalled*: `{"ServiceName": "MalSvc", "ServiceType": 1, "ServiceStartType": 2, "ServiceAccount": "LocalSystem"}`

#### G. `AdvancedHunting-DeviceInfo`
* **Core Fields**:
  * `OSPlatform`: `"Windows10"`, `"Windows11"`, `"WindowsServer"`, `"macOS"`, `"Linux"`.
  * `OSVersion`, `OSBuild`, `OSArchitecture` (`"64-bit"`).
  * `PublicIP`: Sensor egress IP.
  * `LoggedOnUsers`: Stringified JSON array: `"[{\"UserName\":\"alice\",\"DomainName\":\"CORP\",\"Sid\":\"S-1-5-21-...\"}]"`.
  * `IsAzureADJoined`: `true` / `false`.
  * `AadDeviceId`, `DeviceObjectId`: GUID or `null`.
  * `OnboardingStatus`: `"Onboarded"`, `"CanBeOnboarded"`.
  * `ClientVersion`: Sensor agent version (e.g., `10.8210.19041.1001`).

## 4. Timestamp & Dynamic Time Templating

The log schema uses **ISO 8601 UTC timestamps with 7 fractional second digits** (`YYYY-MM-DDTHH:MM:SS.fffffffZ`).

### Timestamp Fields & Relationships:
1. `time` (Outer wrapper): Cloud ingest timestamp.
2. `properties.Timestamp` (Sensor event time): Generated on the endpoint; typically **0–180 seconds earlier** than `time`.
3. `properties.ProcessCreationTime` / `InitiatingProcessCreationTime`: When the active process was instantiated.
4. `properties.InitiatingProcessParentCreationTime`: When the parent process was instantiated (must be $\le$ `InitiatingProcessCreationTime`).

### Macro Templating Syntax:
When generating synthetic events, dynamic timestamp macros calculate chronologically consistent timelines:

* Outer Ingestion: `##$TimeStamp-0d0h2m0s$##` (Format: `2023-10-25T14:30:00.1234567Z`)
* Sensor Detection: `##$TimeStamp-0d0h2m15s$##`
* Process Creation: `##$TimeStamp-0d0h2m16s$##`
* Parent Process Creation: `##$TimeStamp-0d4h30m0s$##`

## 6. Key Constraints & Pitfalls

### Mandatory Fields
* `time`, `tenantId`, `operationName`, `category`, and `properties` must always be present at the top level.
* Inside `properties`, `Timestamp`, `DeviceId`, `DeviceName`, `ReportId`, and `ActionType` are critical for downstream ingestion pipelines and parsers.

### Handling Null Values
* MDE diagnostic streams explicitly output `null` for non-populated keys rather than omitting the key.
* Strings representing empty states often default to `""` or `null` depending on whether the property was applicable (e.g., `AppGuardContainerId: ""`, `InitiatingProcessAccountUpn: null`).

### Stringified Nested JSON Escaping
* Nested objects (`AdditionalFields`, `LoggedOnUsers`, `IPAddresses`, `DnsAddresses`) must be serialized as valid **escaped JSON strings**, not direct JSON child objects:
  ```json
  // Correct
  "AdditionalFields": "{\"IsLocalLogon\":true,\"Upn\":\"user@domain.com\"}"

  // Incorrect (will fail parsing downstream)
  "AdditionalFields": {"IsLocalLogon": true, "Upn": "user@domain.com"}
  ```

### Windows Path & Command-Line Escaping
* Ensure all backslashes in Windows file paths and registry keys are double-escaped:
  * File paths: `C:\\Windows\\System32\\cmd.exe`
  * Registry hives: `HKEY_LOCAL_MACHINE\\SOFTWARE\\Microsoft\\...`
* Quotes in command line parameters must be properly escaped (`"\"C:\\Program Files\\...\""`).

### Hex Hash Formatting
* MD5 (32 chars), SHA-1 (40 chars), and SHA-256 (64 chars) are strictly lower-case hex characters.
* `DeviceId` must be a 40-character lower-case hex string.

### PID & PPID Hierarchy
* Maintain logical PID/PPID structures (e.g., Parent process start time `InitiatingProcessParentCreationTime` must precede child process start time `InitiatingProcessCreationTime`).
* System root processes (`wininit.exe`, `services.exe`, `lsass.exe`) should run as `NT AUTHORITY\SYSTEM` with `S-1-5-18` and `ProcessIntegrityLevel: "System"`.
